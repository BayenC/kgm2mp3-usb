# 1.1.0 版本说明

日期：2026-10-03。本地可安装 APK 已完成，最终界面与操作回归通过，尚未发布 GitHub；SAF 与实体设备项仍待补。

- 主页 USB 提示卡改为输出格式：MP3（默认）、FLAC、WAV、M4A。
- 手机默认下载目录改为 `/storage/emulated/0/kgmusic/download/kgmusic`。
- 主按钮改名「转移」，移除底部格式/原文件/覆盖提示文字。
- 设置移除输出格式和高级设置，固定更新源 `BayenC/kgm2mp3-usb`。
- 按钮、格式和分页面板按住时颜色加深；紧凑布局支持已验证的 320 dp 小屏及字体比例 1.3，保留选歌、转移和取消入口。
- USB 歌曲逐首勾选并确认后可删除；不提供全选，手机和 USB 选择互相独立。
- USB 删除重新核对根目录、装置和歌曲快照，支持取消、部分失败反馈及中断后重新扫描。
- 按参考图重画圆润双音符，保留绿白配色；音符向左微移约 10 px／580 px 预览，四角透明，支持自适应桌面遮罩。
- 使用新包名 `com.kgm2mp3_usb.app` 和新签名；首次独立安装需重新授权，后续同身份更新保留设置。
- 正式包仅保留 ARM64 音讯库，开发测试包另存；最终正式包 23.48 MB，较 1.0 缩小约 51%。
- 更新按数字版本比较并匹配设备架构，验证对应 SHA-256、包名、较高 versionCode 与当前新签名；公开旧版本不提示更新。

当前已通过 54 项 JVM、9 项 Python 检查和 22 项 Android 模拟器测试。SAF 根目录初始授权有 1 项环境阻塞，真实 OTG、车机和其他 Android 版本未实机验证；最终正式 APK 签名与 16 KB 对齐已校验，最终小屏界面、逐首删除确认／取消、实际 MP3 转移和格式保存回归通过。证据与最终安装包信息见 [VALIDATION.md](VALIDATION.md)。

图示微调后的 APK 已重新构建、校验签名／对齐并安装查看桌面图标；功能测试属于图示修改前基线，本轮没有重跑，DEX 与 10 个 ARM64 原生库内容不变。图标预览见 [logo-1.1.png](assets/logo-1.1.png)。
