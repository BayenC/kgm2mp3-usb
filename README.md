# 音樂轉移（kgm2mp3-usb）

構建這個APP純粹是為方便我爸把酷狗音樂下載的歌曲一鍵轉換並轉移到U盤裏，對著Android的文件系統和把kgm格式轉成mp3格式對老人家來說還是太難為了。

## 格式與兼容性

- 正式安裝包支持 Android 8（API 26）及以上的 ARM64 手機，且只含 `arm64-v8a` 原生庫。
- KGM 核心按文件內容識別舊版加密，KGMA 和 `.kgm.flac` / `.kgma.flac` 文件名共用同一解碼流程。
- KGG 與未知加密版本不屬於本版支持範圍。
- 普通 MP3、FLAC、WAV、M4A 等音頻可按目標格式轉換或直接複製。
- 文件授權及移動存儲的可見性、可寫性取決於手機系統、OTG 和文件系統。
- Android 的公開存儲接口把 USB 和可移除 SD 卡都列為移動存儲，不能可靠地把 USB 設備身份對應到卷 UUID。只在檢測到 USB 大容量存儲設備且僅有一個移動存儲卷時自動選擇目標；多個卷時由用戶選擇，已明確選擇的目標會被記住。僅有 SD 卡時不會自動選擇。

## 源碼與第三方組件

- `kgm-core/`：從 OpenConverter 的 Kotlin KGM 實作提取並適配的流式解碼模塊，保留授權和來源記錄。
- `app/`：Android 界面、存儲授權與掃描、轉碼、USB 複製/刪除、更新。
- 音訊轉換使用固定版本的社區維護 FFmpegKit 音頻構建，見 `third_party/`。
